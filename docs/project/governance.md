# Governance proposal

This is a founding proposal. A committee has not yet been formed.

## Participation

Anyone can file an issue, submit an RFC, implement OPP, or contribute fixtures without paying. Public GitHub discussion, review notes, decisions, and release notes are the normal record of work.

Maintainers steward the repository and merge routine changes. A technical steering group approves normative releases after public review. An advisory group provides manufacturing, CAD/CAM, metrology, research, and end-user expertise.

Prospective advisory seats include Siemens/NX, other CAD/CAM vendors, Boeing and other engineering users, NIST/research organizations, manufacturers, metrology vendors, and independent engineers. Names are a participation goal, not a claim of membership or endorsement.

## Proposed safeguards

At formation, publish maintainers and affiliations. Reserve seats across user and implementer groups. An employer and its affiliates should not control a steering-group majority. Advisors do not get an exclusive veto. Conflicts of interest are disclosed. No paid membership buys normative control or early exclusive access.

Seek consensus in public. If consensus fails, publish alternatives and reasons before a recorded two-thirds steering-group vote with a quorum of two-thirds. Appeals receive a documented response. These voting rules require founding review before adoption.

## Releases

Each normative change needs a problem statement, examples, schema changes, migration impact, tests, and a public review period of at least 30 days for stable releases. Breaking changes receive a new version; files never depend on “latest.” Implementation reports must identify exact versions and tested capabilities.

Apache 2.0 is the initial repository license. Contributors must have the right to contribute their work. Do not copy restricted standards text, proprietary CAD data, supplier records, or third-party code without its applicable terms. A future foundation and any additional patent commitment require their own public proposal.
